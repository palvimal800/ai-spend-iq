# AI Spend IQ

AI Spend IQ is a lightweight audit dashboard that helps teams analyze spending on AI tools like ChatGPT, Claude, Cursor, Gemini, and Copilot.

## Features
- AI tool selection
- Spend tracking
- Team size input
- Seat management
- Use case tracking
- Audit generation

## Tech Stack
- Next.js
- React
- Tailwind CSS
- TypeScript
